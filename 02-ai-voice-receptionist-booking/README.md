# AI Voice Receptionist & Appointment Booking

## Problem
Missed calls and manual appointment booking create lost opportunities and admin overhead.

## Solution Pattern
- Incoming call answered by AI voice agent
- Intent detected (booking, enquiry, reschedule)
- Information collected and validated
- Calendar availability checked
- Appointment booked and confirmed
- CRM record created/updated
- Notification sent to business

## Key Components
- Voice agent (Vapi or similar)
- Calendar integration
- CRM sync
- Confirmation messaging
